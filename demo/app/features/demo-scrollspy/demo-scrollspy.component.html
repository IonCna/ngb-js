Overview

Scrollspy tracks the visible fragment inside a scrolling container and keeps related menu items in sync.

This demo uses the root directive, a menu directive, four menu items, and four fragments in the same scroll container.

Setup

Each content section receives a unique fragment id. The menu buttons point to those ids with ngb-scroll-spy-item.

Clicking a menu item scrolls the container to the matching fragment.

Usage

The active class is applied automatically to the current item, so Bootstrap list groups show the selected section without extra demo code.

The directive also emits active-change so the component can display the active id.

API

The service accepts root margin, threshold, scroll behavior, and a custom process function for advanced matching.
